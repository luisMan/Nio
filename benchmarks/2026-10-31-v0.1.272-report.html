Read this before quoting the numbers

Nio as shipped picks its own models. In this run it sent 101 of its requests to Sonnet 5.5 ($2.10 of its $2.51), with GPT-5.1, Haiku 4.5 and one Opus 5.5 call for other roles. Every other arm runs Sonnet 4.6. The Nio row therefore mixes what Nio does with a newer model.

The pinned row is the same-model comparison: Nio with Sonnet 4.6 in every role finished 15/15 at $0.486 per finished task, against OpenCode's 12/15 at $0.490 and Gentle-AI's 14/15 at $0.656.

The claim the numbers support: on our five-task benchmark, with both running Claude Sonnet 4.6, Nio finished as many tasks as Gentle-AI or more, at 21–35% lower cost.

  • Not supported: "more reliable." Nio finished one more task in one run and tied in the other. One task in 15 is within the noise of three runs per task.
  • Not supported: "faster." On v0.1.272, Gentle-AI was faster on most tasks: fix-site 306 s against 551 s, build-app 176 s against 452 s, fix-tests 81 s against 132 s.
  • Not supported on its own: "about 4x cheaper." That compares Nio's default ($0.167 per finished task, mostly Sonnet 5.5) with Gentle-AI on Sonnet 4.6, so it includes the model difference. Quote it only next to the pinned number, and say the models differ.
  • Not supported: "better in general." The evidence is five tasks on one web project, with Gentle-AI on OpenCode. It says nothing about other kinds of work or other models.

How the prices are calculated

The costs are estimates, not invoices. For every arm we count the tokens of every model request in every run, then price them with the providers' list prices per million tokens. All arms use the same price table.

  • Where the token counts come from. Nio: the usage log of the Nio gateway each run goes through. OpenCode and Gentle-AI: OpenCode's own session records, including the sub-agents Gentle-AI delegates to. Raw: the usage the Anthropic API returns with each answer.
  • Four kinds of tokens. Uncached input, cache reads (prompt text the provider already has cached), cache writes (prompt text stored in the cache for later requests) and output. Each has its own price.
  • Spent is the sum over all 15 runs of an arm, including runs that failed. Per finished task is that sum divided by the number of runs that passed every check.
  • Image generation was off for Nio in this benchmark, so no image costs are included. Requests cut off by a timeout are not counted for any arm.

Other things the run shows

  • Raw Sonnet 4.6 is the cheapest where it passes, but it never passed memory-2 (8 of 9 checks every time) or fix-tests (at most 2 of 11).
  • OpenCode also missed memory-2 in all three runs, on the same check. One of its fix-site runs used the full 2,700 s and asked for 16 approvals.
  • Nio asked for at most one approval per run. Its Sonnet 5.5 calls read 81% of their prompt from cache.
  • The two newest fixes in this release, display-only pages no longer refused as placeholders (v0.1.271) and the browser check reporting a request that never finishes (v0.1.272), are not exercised by these five tasks.

How it was run

  • Each arm ran the same five tasks three times, in a fresh copy of the same seed project, through the same automated harness. Nio ran the released v0.1.272 binary.
  • Group A (Nio, raw, OpenCode, Gentle-AI) started 17:52 UTC; group B (Nio pinned) started 21:12 UTC. Budget cap $70; the run spent $27.42 in total.
  • The scorer's own installs, builds and browser checks are not counted in any arm's time.
  • The 29 Oct row of the Gentle-AI comparison comes from an earlier run of the same harness, tasks and seed project.

Three runs per task is a small sample: one slow or failed run moves a mean a lot. Treat differences under about 25% as noise.
