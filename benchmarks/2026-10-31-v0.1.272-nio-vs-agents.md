# Nio v0.1.272 vs other agents — October 31, 2026

We gave five coding tasks to five setups, three runs each, on the same seed
project: Nio, Nio with every role pinned to Claude Sonnet 4.6, OpenCode,
OpenCode with Gentle-AI, and Claude Sonnet 4.6 called directly. Nio finished
all 15 runs, and so did Nio pinned to Sonnet 4.6.

With both on Claude Sonnet 4.6, Nio finished as many tasks as Gentle-AI or
more, at 21–35% lower cost, in our two most recent runs.

The full report, with every task and every setup, is
[here](https://docs.nioai.run/benchmarks/2026-10-31-v0.1.272-report.html).

What the numbers do not show:

- **More reliable.** Nio finished one more task in one run and tied in the
  other. One task in 15 is within the noise of three runs per task.
- **Faster.** On the same model, Gentle-AI was faster on most tasks: fix-site
  306 s against 551 s, build-app 176 s against 452 s.
- **Better in general.** Five tasks on one web project, with Gentle-AI on
  OpenCode, say nothing about other kinds of work or other models.

## How the costs are calculated

Costs are estimates, not invoices. We count the tokens of every model request
in every run: for Nio from its gateway's usage log, for OpenCode and Gentle-AI
from OpenCode's session records (including Gentle-AI's sub-agents), and for the
direct call from the usage the API returns. Each token is priced at the
provider's list price; all setups use the same price table. "Spent" counts all
15 runs, failed ones included; "per finished task" divides it by the runs that
passed every check.

| Model | Input | Cache read | Cache write | Output |

| Claude Sonnet 5.5 | $2.00 | $0.20 | $2.50 | $10.00 |
| Claude Opus 5.5 | $4.00 | – | – | $20.00 |

US dollars per million tokens, list prices as of October 2026.

Example, the two same-model totals on October 31:

- Nio pinned: 0.659M uncached input × $3 + 3.299M cache reads × $0.30 +
  0.441M cache writes × $3.75 + 0.177M output × $15 = **$7.28**
- Gentle-AI: 0.0004M × $3 + 16.696M × $0.30 + 0.700M × $3.75 + 0.104M × $15
  = **$9.19**

Gentle-AI sends almost all of its prompt from cache, but its prompts are much
larger: 17.4 million prompt tokens against Nio's 4.4 million.

## How it was run

Tasks: fix-site (make a broken Next.js streaming site display correctly
without breaking its other pages), build-app (build a Next.js movie watchlist
app), memory-1 (build a Next.js tip calculator), memory-2 (in a new session,
add the currency converter page "we agreed on last time" to it), and
fix-tests (fix the bugs in a Python library until its pytest suite passes,
without touching the tests). Each setup ran each task three
times in a fresh copy of the same seed project, through the same automated
harness, and was scored by browser and test checks after every turn. Nio ran
the released v0.1.272 binary. The direct call runs no commands, so its time is
the model's answer only. Three runs per task are few: one slow or failed run
moves an average a lot, so treat differences under about 25% as noise.
